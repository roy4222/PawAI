## Bottleneck being broken

使用者考慮用 YOLO-pose（「效果好像也不錯，手勢也好像有」）取代或補強現役 MediaPipe pose/gesture。要在上機測試前裁定：YOLO26-pose 進不進 bench 名單？核心算盤是「一顆 GPU 模型（person bbox + 多人 17kpt）能不能換掉/補強兩顆 CPU 模型」，以及手勢的 YOLO 路線到底存不存在。不裁定就會變成「聽說不錯」的無限循環。

This goal exists to produce a falsifiable verdict on this specific bottleneck.

## Context

- Project: 老人與狗 / PawAI
- 現役：pose = MediaPipe Pose（18.5 FPS CPU、GPU 0%、33 kpt 含 z）→ 自製規則判 sitting/fallen；gesture = MediaPipe Gesture Recognizer（7.2 FPS CPU）；object = YOLO26n GPU。三感知全 CPU 是 L3 壓測過關（RAM 1.2GB/52°C/GPU 0%）的基石

- 17 kpt 的能力邊界：sitting 判定需要的 hip/knee/ankle 都在；但 MediaPipe 的 z 軸與 33 點細節（腳跟/腳尖）現役規則用到哪些？（讀 vision_perception 規則代碼，列出每條規則依賴的 kpt）

- 與 478_SC ensemble 路線的關係：SC（外觀分類）+ YOLO-pose（幾何）+ MediaPipe（幾何）三選二的組合空間——避免三條 sitting 線同時開工
